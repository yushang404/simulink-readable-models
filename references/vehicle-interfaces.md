# 车辆控制接口检查

仅在车辆、MPC 或 CarSim 模型中读取；不将这份约定强加给其他领域模型。

## 在连接之前明确

| 项目 | 需要确认的内容 |
| --- | --- |
| 坐标系 | 全局或车体坐标；坐标轴方向；角度零方向及正方向 |
| 参考点 | 车辆质心、后轴中心或其他点；参考轨迹使用的参考点是否一致 |
| 状态 | 每个元素的物理量、顺序、单位、测量或估计来源 |
| 控制量 | 速度还是加速度；前轮转角还是方向盘转角；指令还是实际值 |
| 单位 | rad/deg、m/s/km/h 等转换明确放在接口区域，避免隐式混用 |
| 时间 | 控制周期、车辆积分步长、接口更新时间和采样保持方式 |
| 责任 | 哪个模块负责纵向速度、横向转向、执行器动态及限幅 |

## 可选示例：后轴参考点接口

若任务选择后轴参考点，可采用状态 `[X_r; Y_r; phi]`，单位 `[m; m; rad]`；控制为 `[v_r; delta_f]`，单位 `[m/s; rad]`。`v_r` 为后轴参考点速度，`delta_f` 为前轮转角。本例不强制其他项目采用相同接口；复用前核实当前源码及用户要求；不要未经说明改为质心状态或 `[a; delta]`。

固定车速、仅优化转向时，把该假设写清楚。误差计算需与参考点、坐标系和角度处理一致。诊断输出与控制输出分开；优化退出状态、耗时和约束检查不应被误当成车辆状态。

## CarSim 联动时再验证

确认实际数据集中的输出参考点、信号定义、角度单位及转向输入含义；需要质心与后轴转换时，根据坐标约定和几何参数推导并验证，不能只改标签。

确认内置驾驶员或速度控制是否仍在工作，避免与外部控制重复施加指令。先核对单个接口的量纲、正负方向和响应，再运行闭环代表工况。

MATLAB 能运行、Simulink 能运行、CarSim 已安装都不等于联合仿真已通过。未实际联动时，交付中明确写“接口预留，联动未验证”。
